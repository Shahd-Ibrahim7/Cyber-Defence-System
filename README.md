## 🚀 Project Overview

ECDTMS is an enterprise-level cybersecurity management system designed to simulate real-world cyber defense operations.

The platform provides:

- 🔥 Threat Detection & Monitoring
- 🛡️ Incident Response Management
- 📊 Security Dashboard
- 👤 Authentication & User Roles
- 💻 Device Monitoring
- 📑 Incident Reporting
- ⚡ JavaFX Interactive GUI
- 🗃️ MySQL Database Integration
