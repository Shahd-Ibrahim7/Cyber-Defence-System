# 🛡️ ECDTMS – Enterprise Cyber Defense Threat Management System

> A professional desktop-based Cybersecurity Threat Management Platform built using Java OOP principles, JavaFX GUI, and MySQL integration.

---

## 🚀 Project Overview

ECDTMS is an advanced cybersecurity management system designed to simulate real-world enterprise cyber defense operations.

The system provides:

- 🔥 Threat Detection & Monitoring
- 📊 Security Dashboard
- 🛡️ Incident Response Management
- 👤 Authentication & User Roles
- 💻 Device Monitoring
- 📑 Incident Reporting
- 🗃️ Database Integration
- ⚡ JavaFX Interactive GUI

---

## 🧠 System Architecture

```text
Model Layer
   ↓
Repository Layer
   ↓
Service Layer
   ↓
Controller Layer
   ↓
JavaFX GUI (FXML)
```
