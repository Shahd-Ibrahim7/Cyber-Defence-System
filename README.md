# ECDTMS – Enterprise Cyber Defense Threat Management System 🔐

A desktop-based Cybersecurity Threat Management System developed using Java OOP principles, JavaFX GUI, and MySQL database integration.

## 🚀 Features
- Threat Management
- Incident Tracking
- User Authentication System
- Security Dashboard
- Device Monitoring
- Incident Reports
- JavaFX Graphical User Interface
- MySQL Database Integration

## 🛠 Technologies Used
- Java
- JavaFX
- MySQL
- JDBC
- Object-Oriented Programming (OOP)

## 📂 Project Structure
- Model Layer
- Repository Layer
- Service Layer
- Controller Layer
- JavaFX Views (FXML)
